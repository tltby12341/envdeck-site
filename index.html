Everything You Need in One Chrome SidePanel

1. Request & Response Headers + URL Rules

  • Set, append, or remove Request & Response headers via MV3 declarativeNetRequest.
  • One-click presets: Bearer Auth, Local CORS Unlock, Force No-Cache, Spoof IP, EU Locale, Mobile Safari UA.
  • Inject or strip URL query params (?debug=true) or redirect API calls to localhost.
  • Copy active request headers as a ready-to-run curl command.

2. Cookies, Storage & Session Snapshots

  • Full Cookie editor supporting Secure, HttpOnly, SameSite, and __Host- rules.
  • Inspect and edit live localStorage and sessionStorage.
  • Copy cookies as JSON, Cookie Header string, or Netscape .txt; import JSON arrays.
  • One-Click Snapshots: capture a tab's cookies + storage and switch test accounts with auto-reload.

3. Smart Form Filler & Bug Magnet Payloads

  • Fill entire forms locally with Alt+Shift+F using React/Vue compatible native event dispatch.
  • Save custom QA form override templates for repeatable signups and checkouts.
  • Built-in XSS, SQLi, RTL/Emoji/Unicode, 256/1000-char overflow, and numeric boundary strings in SidePanel and right-click menu.

4. AES-256-GCM Encrypted Team Sharing

  • Export profiles with PBKDF2-SHA256 (250k iterations) + AES-256-GCM passphrase encryption.
  • Safely share bug reproduction environments (including cookies & tokens) over Slack or Jira.
  • Or export plain JSON with automatic one-click secret redaction.
