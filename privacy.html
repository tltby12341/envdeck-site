Privacy Policy — EnvDeck

Effective Date: November 25, 2026
Summary: EnvDeck operates 100% locally inside your browser and makes zero outbound network requests. We do not collect, transmit, or sell any browsing data, headers, cookies, or personal information.

1. Data Collection

EnvDeck collects zero personal data, zero browsing history, zero analytics, and zero telemetry. The extension contains no tracking scripts and never contacts developer-controlled or third-party servers.

2. Local Data Storage

All environment profiles, HTTP header rules, URL redirect rules, captured cookie/storage snapshots, and QA form templates are stored strictly on your device using Chrome's local storage API (chrome.storage.local).

3. Permissions Usage

  • declarativeNetRequest & host permissions: apply user-defined header modifications and URL rules locally.
  • cookies: read, create, edit, delete, and snapshot cookies on the active tab when initiated by the user.
  • scripting & activeTab: fill forms, inject QA edge-case strings, and inspect/restore web storage only upon explicit user action.
  • sidePanel, contextMenus, storage, tabs: render the workbench UI and persist local profiles.

4. Team Export & Encryption

Profile exports are generated entirely locally in your browser. Encrypted team bundles use the browser's native Web Crypto API (PBKDF2-SHA256 with 250,000 iterations + AES-256-GCM). Your passphrase is never stored or transmitted.

5. Payments & Licensing

Optional EnvDeck Pro purchases are processed externally via Stripe Checkout. License activation inside EnvDeck uses offline key verification so the extension remains completely network-free.
